# Reliable Data Transfer over UDP

A socket-level reliable file transfer system implemented over UDP.

## Protocols

- Stop-and-Wait ARQ
- Go-Back-N ARQ
- Selective Repeat ARQ

## Features

- Sequence numbers
- Acknowledgements
- Checksums
- Retransmission
- Adaptive RTO
- Channel emulation
- File integrity verification
